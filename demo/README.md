# uu · 游戏纪念册

React + Vite 纯静态前端，13 款游戏，支持视频、照片组和文字回忆。每次进入默认第一款游戏，进入前的 URL hash 不影响初始选择。新增记录主要修改 `public/content.json`，保持 `schemaVersion: 3`。完整字段说明和可复制示例见 [CONTENT.md](./CONTENT.md)。

- `title` 为游戏名；`firstTime` 为第一次游玩日期（`YYYY-MM-DD`）；`hours` 为总时长，单位小时，未知填 `null`。
- 游戏自动按 `firstTime` 从早到晚排列；同日保持 JSON 顺序，每次进入从排序后的第一款开始。
- `memories` 按 JSON 顺序展示，支持 `video`、`gallery`（一张或多张）、`text` 和 `featuredVideo`。回忆自己的 `date` 不影响游戏排序。
- 视频 `src` 留空显示封面预览，填写真实路径或 HTTPS 直链后使用播放器。双影奇境 `split-special` 为特别剪辑预留。
- `layout` 可选 `auto` 或现有六种编排。预设只用于匹配的内容组合；增减、调整回忆顺序后自动流式排列，避免重叠。
- `demoMode: true` 显示演示说明；替换完真实内容后改为 `false`。

本地素材放在 `public/assets/`，配置填写 `assets/文件名`。构建会校验本地引用是否存在；远程链接不会在构建时请求，播放可用性需要单独验证。大视频后续接入外部存储即可，不建议提交进 Git。

日期、时长和文字仍为 mock。官方素材来源见 `public/assets/steam/sources.json`，蛋仔派对来自网易手游宣传素材。角色采用官方宣传素材辅助提取，少量遮挡部位可能经过补全。

## 交互约束

滚轮连续移动，无模拟惯性或切换冷却。停止输入 150ms 后就近对齐，260ms 内完成吸附，再切换右侧；点击按距离约 320–650ms 移动。新输入从当前显示位置接管；首尾越界尾事件不延后停稳。手机采用横向目录。

人物接近中心渐变至 1.14 倍，剪影小幅摆动，停稳时前景轻浮动。分隔线保留黄、橘双线和各自 2px 白边；左侧色区与橘线共享变换。镜头通过扩展画布避免盒盖裁切，不缩小盒子。

## 入口与生日

当前 `src/entryRules.js` 中 `ENTRY_BLOCKED=true`：正确密码后只显示「不准进」临时拦截页，不挂载生日、盒子或纪念册。点击纸牌可触发敲门反馈。撤除时将此开关改为 `false`，即可恢复原流程；没有查询参数或页面按钮可以绕过。

输入 `1020`，电脑端按回车进入；移动端显示密码框右侧箭头，可点击进入，无需数字键盘提供回车键。最多可输入 8 位。无持久化解锁，刷新或重播需再次输入。输入页保留原生橘色光标、空输入待机动画和长度联动。

`src/entryRules.js` 的 `BIRTHDAY_TEST_MODE=true` 仍保留：任意日期解锁都播放 3 秒生日庆祝，自动结束，无继续按钮，可按 Esc 跳过。用户审核确认后再改为 false，恢复每年北京时间 10 月 20 日触发。

口令只用于进入仪式，纯静态页面及素材并非受保护资源；需要私密访问时应在托管层鉴权。
