# uu · 游戏纪念册

React + Vite 纯静态前端，11 款游戏，支持视频、照片组和文字回忆。每次进入默认第一款游戏，进入前的 URL hash 不影响初始选择。新增记录主要修改 `public/content.json`，保持 `schemaVersion: 4`。完整字段说明和可复制示例见 [CONTENT.md](./CONTENT.md)。

- `title` 为游戏名；`playPeriod` 为游玩覆盖周期（`start` / `end`，格式 `YYYY-MM-DD`，未知填 `null`）；`hours` 为已提供记录累计小时数，未知填 `null`。
- 游戏自动按周期起点从早到晚排列；同起点保持 JSON 顺序，未知周期排在最后。目录与内容标题均展示起止周期，每次进入从排序后的第一款开始。
- `memories` 按 JSON 顺序展示，支持 `video`、`gallery`（一张或多张）、`text` 和 `featuredVideo`。图片组标题与每张图的说明均可省略，每张图只需 `src`。回忆自己的 `date` 不影响游戏排序。
- 视频 `src` 留空显示封面预览，填写真实路径或 HTTPS 直链后使用播放器。已按上传清单接入 72 个 OSS 视频；双影奇境 `split-special` 接入 `lucky.mp4`，保留独立宽幅样式，页面不显示“特别剪辑”或英文标记。
- `layout` 可选 `auto` 或现有六种编排。预设只用于匹配的内容组合；增减、调整回忆顺序后自动流式排列，避免重叠。
- `demoMode` 控制页尾说明；按用户要求现为 `false`，不展示周期/时长和演示内容小字。部分回忆文字仍为可编辑草稿。

本地素材放在 `public/assets/`，配置填写 `assets/文件名`。构建会校验本地引用是否存在；远程链接不会在构建时请求，播放可用性需要单独验证。大视频后续接入外部存储即可，不建议提交进 Git。

生产环境的 60 张图片已通过 `oss-images.json` 映射至 `https://uu-memories-1.oss-cn-hongkong.aliyuncs.com/uu-album/`，包括真实截图、角色与剪影、头像、视频封面和开屏纹理，沿用已上传的分类目录与带内容哈希的 WebP。无需自定义素材域名证书；防盗链允许站点来源，CORS 允许 `https://7uuuuuuu.cn`。图片、预加载和 WebGL 使用匿名 CORS，复用浏览器缓存。JSON 仍填写原路径，原图保留；开发模式直接读本地原图，不依赖 OSS 的生产域名白名单。

未配置 OSS 映射的本地图片仍在构建时生成带内容哈希的 WebP，最长边不超过 1440px，头像不超过 256px，保留透明通道，只采用体积更小的结果。新增图片应先压缩上传、更新 `oss-images.json` 的对象路径、字节数和 SHA-256，再发布；外部链接和视频地址保持原值。

密码页显示后即后台读取并校验内容，优先预加载首款游戏的角色、头像、截图和视频封面，再预加载相邻角色、盒子照片及其余目录角色；最多并行 3 张。箱子和相册复用同一份内容及图片缓存，仍在解锁后才加载相册与 Three.js。图片失败不阻挡输入或进入；真实视频文件不参与提前下载。临时拦截开关开启时不预加载。

游玩周期与时长已根据用户提供的两张周报截图去重累计，Nomad Drive 为 Demo，无周报数据，按用户补充记为 2026.8.31–9.6、7h。已接入 30 张真实截图（`picture.zip` 28 张及后补逃生：试炼 2 张），覆盖 10 款游戏，按游戏放在 `public/assets/games/`，来源映射见其下 `sources.json`。另按用户清单接入 72 个 OSS 视频，视频标题取文件名，描述为据名称撰写的可编辑草稿，不代表逐条观看结论；本地路径仅用于取名，未写入网页。PEAK 尚无视频，仅展示照片与文字，不保留视频占位卡片。回忆文字与部分宣传素材仍为演示内容。统计和截图分类依据见 CONTENT.md。官方素材来源见 `public/assets/steam/sources.json`。角色采用官方宣传素材辅助提取，少量遮挡部位可能经过补全。

## 交互约束

滚轮连续移动，无模拟惯性或切换冷却。停止输入 150ms 后就近对齐，260ms 内完成吸附，再切换右侧；点击按距离约 320–650ms 移动。新输入从当前显示位置接管；首尾越界尾事件不延后停稳。手机采用横向目录。

人物接近中心渐变至 1.14 倍，剪影小幅摆动，停稳时前景轻浮动。分隔线保留黄、橘双线和各自 2px 白边；左侧色区与橘线共享变换。镜头通过扩展画布避免盒盖裁切，不缩小盒子。

## 入口与生日

当前 `src/entryRules.js` 中 `ENTRY_BLOCKED=false`：临时「不准进」拦截页已关闭，正确密码后恢复生日祝福、盒子开屏与纪念册流程；保留拦截组件及开关，后续可重新启用。

输入 `0621`，电脑端按回车进入；移动端显示密码框右侧箭头，可点击进入，无需数字键盘提供回车键。最多可输入 8 位。无持久化解锁，刷新或重播需再次输入。输入页保留原生橘色光标、空输入待机动画和长度联动。

`src/entryRules.js` 的 `BIRTHDAY_TEST_MODE=true` 仍保留：任意日期解锁都播放 3 秒生日庆祝，自动结束，无继续按钮，可按 Esc 跳过。用户审核确认后再改为 false，恢复每年北京时间 10 月 20 日触发。

口令只用于进入仪式，纯静态页面及素材并非受保护资源；需要私密访问时应在托管层鉴权。

当前开屏祝福仅显示“生日快乐”；重播开屏按钮仅显示循环箭头，保留辅助功能名称。盒内照片为原 PEAK 浅紫山景、用户 PEAK 合照和渔力全开海边截图，复用现有 OSS 图片及预加载。
